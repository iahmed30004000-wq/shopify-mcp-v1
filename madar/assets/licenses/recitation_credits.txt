Madar – Quran recitation (lib/features/recitation)
===================================================

Recitation audio
----------------
Source: EveryAyah – https://everyayah.com/data/<folder>/<SSSAAA>.mp3
(per-ayah MP3 files of human reciters; Madar never uses generated voices
for the Quran).

Madar bundles NO recitation audio. A file is fetched only when the user
presses play (streaming) or starts a download; downloads are kept in the
app's private storage for the user's own listening and are never shared.

Licence status: everyayah.com publishes no licence or terms for these files
(an audit by risan/quran-json, src/quranjson/config.py, records the status
as "unknown": its licence/terms paths return 404). Madar therefore links to
the files rather than redistributing them, and credits the site and every
reciter. Could not be re-checked from the build machine (everyayah.com is
not reachable there).

Folder names were verified against two published copies of everyayah's
recitation list (https://everyayah.com/data/recitations.js):
  * risan/quran-json – data/audio/everyayah.json
    https://github.com/risan/quran-json
  * Alfanous – src/alfanous/configs/recitations.json
    https://github.com/Alfanous-team/alfanous
(Husary_Muallim_128kbps, Yasser_Ad-Dussary_128kbps and
Nasser_Alqatami_128kbps appear only in the first, newer copy.)

Basmala convention: ayah 1 of every surah except al-Fatihah and at-Tawbah is
preceded by file 001001 (al-Fatihah's first ayah), as in the quran.com
Android app (quran/quran_android, AudioQueue.kt) – convention only, no code
taken.

Ayah counts
-----------
The Hafs (Kufan) ayah counts (6236) in surah_ayah_counts.dart are the same
in both lists above (facts, not a copyrighted work); they match Tanzil's
quran-data (CC BY 3.0, https://tanzil.net).
